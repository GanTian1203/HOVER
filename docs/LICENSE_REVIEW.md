# Author-owned software license candidates — no license adopted

The rights holders must approve a license for the HOVER implementation before
release. All eight forecasting backbones are external dependencies in this
package. Their own terms apply to separately obtained code. See the
[external model registry](EXTERNAL_MODEL_REGISTRY.md) for pinned versions and
license sources. OLinear is supplied separately by a user with an applicable
permission basis. Data, manuscript text, reference results and any optional
weights have separate release considerations.

| Candidate | Practical fit | Obligations and tradeoffs |
|---|---|---|
| MIT | Short, permissive terms for the authors' own code; simple downstream reuse | Retain copyright and permission notice; no Apache-style explicit patent grant text |
| Apache-2.0 | Explicit patent grant within its stated scope | Retain the license and applicable notices, identify modified files and observe the patent terms |

MIT is a candidate if the rights holders prefer a short permissive license.
Apache-2.0 is a candidate if they prefer its express patent grant and notice
framework. The license decision applies to author-owned files. The upstream
projects retain their own terms, as recorded in the
[third-party notices](../THIRD_PARTY_NOTICES.md).

Before adopting either candidate, establish who can grant the rights: each
contributing author, any employer/university assignment, funded-project terms,
and applicable supervisor/institution approval. Authorship alone is not a
verified ownership record. No institution policy or written assignment was
provided for this review, so neither candidate has been installed as LICENSE.
Paper text, data and model weights are separate release decisions.

Primary texts: [MIT](https://opensource.org/license/mit),
[Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0), and
[GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).
