# OLinear source and licensing

OLinear uses the [official pinned source](https://github.com/jackyue1994/OLinear/tree/f168e01a3e0e316ad98330b5e77afed1f77b0af5).
The pinned tree and README did not establish a model redistribution grant.
Some utility files contain third-party notices that apply to those files.
See the [source review](../manifests/phase3_olinear_permission_review.json)
for the recorded provenance.

The repository includes the HOVER-side interface. To run OLinear, obtain the
pinned source separately under an applicable use basis and follow the
[local registration instructions](EXTERNAL_MODEL_GUIDE.md). OLinear acquisition
is local-only. The loader requires a commit, a nonempty `permission_basis`, and
matching hashes. The registration records the user's basis for use. It cannot
grant rights to the source.
